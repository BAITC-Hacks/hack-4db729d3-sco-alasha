# Контрактные проверки

Из корня `money-graph/`, в окружении с установленными зависимостями проекта:

```bash
pip install pytest
python pipeline.py
pytest -q
```

На Windows при ошибке кодировки терминала запускайте пайплайн как `python -X utf8 pipeline.py`.

Восемь тестов читают `out/nodes_roles.csv`, `out/clusters.csv`, `out/top_nodes.csv` и `data/nodes.parquet`. Пути определяются относительно файла тестов, `gid` в CSV читается как `int64`. Проверяются полнота узлов, словарь ролей, заполненность и числовые основания evidence, диапазоны скоров, кластеры, топ, обрыв на четвёртом колене и роли seed.

Если каталога `out/` нет, тесты пропускаются. Если каталог существует, но файл отсутствует или контракт нарушен, тесты завершаются ошибкой. Тесты не запускают пайплайн, не изменяют выгрузки и не обращаются к LLM/MCP. Проверка контрактов не оценивает точность модели.

`tests/test_extras.py` требует предварительного запуска пайплайна (без пропуска при отсутствии результатов).
Проверяет дополнительные колонки, долю аномалий среди активных узлов, дробление по исходным транзакциям,
граничные условия четырёх типов запросов, сохранение количества ролей, счётчики `extras`, карточки,
регистрацию девяти инструментов и REST API с gid в строковом виде. Внешние LLM и сетевые MCP-серверы
не вызываются; API проверяется локально через TestClient. Полный запуск: `pytest -q tests`.
